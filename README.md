# make-video-skills

Claude Code skills for making videos.

| Skill | What it makes |
|---|---|
| [`documentary-video`](documentary-video/SKILL.md) | YouTube history documentaries in a hand-embroidered tapestry style: short (~2 min) or long-form built in 2-minute parts with saved progress. ElevenLabs voiceover, Google Flow images + image-to-video clips, ffmpeg assembly with seamless joins. |

## Use in a project
Link (or copy) a skill folder into the project's `.claude/skills/`:

```sh
ln -s /path/to/make-video-skills/documentary-video /path/to/project/.claude/skills/documentary-video
```
